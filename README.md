# Mystery Brunch – „Tod beim Brunch"

Mord-Mystery für **9 Personen**: du (Erzähler + Opfer) und 8 Verdächtige.
**Dauer: knapp 2 Stunden** (bis zur Enthüllung), 5 Runden, 19 Beweiskarten, 24 Impuls-Karten.

---

## 🚀 Schnellstart

1. **Lies** [`spielleitung/00-spickzettel.md`](spielleitung/00-spickzettel.md) – die ganze Lösung auf einer Seite.
2. **Drucke** die 8 Rollenkarten aus [`rollen/`](rollen/) (einzeln!), die Beweiskarten, die Impuls-Karten und die Detektiv-Bögen.
3. **Sortiere** in **5 Umschläge R1–R5** (Beweise) und **3 Umschläge I2–I4** (Impulse).
4. **Lies die Rundenkarten einmal laut**: [`spielleitung/04-moderations-skript.md`](spielleitung/04-moderations-skript.md) (Begrüßung), dann [`runden/`](runden/). Das ist dein Skript.

## Setup

- **Tatort:** Stuhl mit Erwins Mantel, Hut und Brille, davor der **umgekippte silberne Thermobecher** mit kaltem Kaffeerest – die Mordwaffe.
- **Herr Vogel trägt eine graue Strickjacke.** Sie taucht auf drei Beweiskarten auf.
- **Name-Tags**, **Detektiv-Bögen**, Stifte → [`material/`](material/)
- **Drei Beweise bekommen Spieler mit ihrer Rollenkarte:** Selfie → Nora, Taxi-Quittung → Greta, Handy-Log → Felix.
